Requisitos

  • Android 7 ou superior; IA local em Android 64-bit, recomendado celular com pelo menos 6 GB de RAM e 3,2 GB livres.
  • Windows 10/11 64 bits para o instalador Electron.
  • Linux x86_64 com FUSE para o AppImage.
  • O APK não inclui os pesos do modelo: o celular baixa uma vez o arquivo oficial de 2,59 GB; o download exige internet e pode consumir dados móveis.
  • O chat local não exige assinatura nem API paga; hardware, eletricidade e conexão para baixar o modelo não são fornecidos pelo projeto.
  • Após baixar o modelo, chat local e histórico ficam no celular; desempenho depende do processador, memória e espaço disponíveis.
