1 · Parear este computador

        
Gere um token local, copie-o para o plugin JARVES Studio Bridge e use o endereço mostrado aqui. O token vale somente enquanto este servidor estiver aberto, só aceita conexões locais e renová-lo descarta scripts ainda pendentes.

2 · Enviar um script Luau

        
Revise o código antes de enviar. O JARVES não executa scripts: o plugin mostra uma prévia e só cria o objeto no Studio após você clicar em “Inserir no Studio”.

        
        
        
        

      

      

        
Instalação e suporte Linux

        
    
          
  1. Baixe o código do plugin JARVES Studio Bridge.
    2. 
          
  2. No Roblox Studio, crie um Script, cole o arquivo, selecione-o no Explorer e use Plugins → Save as Local Plugin.
    3. 
          
  3. Ative solicitações HTTP em File → Experience Settings → Security → Allow HTTP Requests e permita o acesso local quando solicitado.
    4. 
          
  4. Abra o plugin, cole o endereço e token acima, conecte e aprove cada inserção no próprio Studio.
    5. 
        

        
A Roblox oferece Studio oficialmente para Windows e macOS, não Linux. No Linux, essa ponte pode funcionar com Studio executado via Wine, mas Wine não é suportado oficialmente e atualizações podem quebrar compatibilidade. JARVES e o plugin não instalam nem iniciam o Studio.

Servidor para este celular

        
O botão IA local do APK executa um modelo no próprio celular, sem PC; o primeiro download ocupa 2,59 GB e o aparelho precisa de bastante memória. Esta tela web continua oferecendo conexão opcional ao servidor JARVES/Ollama em outro computador para as ferramentas completas.

        
        
        

      

      
Voz do navegador
A voz e a entrada por microfone usam os recursos instalados no seu dispositivo/navegador; elas não alteram a voz do modelo de texto.

        
        
        
        
      

      

        
Fluxo de criação: pesquisar, planejar e executar

        
A pesquisa web é opcional e envia a consulta ao DuckDuckGo. A IA usa o provedor selecionado para planejar; provedores remotos podem cobrar, então escolha Ollama para evitar cobrança por chamada. Revise e confirme antes de executar: as etapas geram respostas/código como texto, não rodam programas nem criam APK/EXE.

        
        
        

          
          
          
          
        

        
Ative “Pesquisa web” nas configurações de IA para liberar a etapa de pesquisa.

        

        
    
        
    
        
        
      
    
      
    
        
    Ajuda para corrigir um erro
    
        
    Cole a mensagem de erro ou código, ou carregue um arquivo de texto/código. O assistente prepara uma sugestão no Chat para você revisar; nada é executado nem alterado automaticamente.
    
        
        
        
        
        
    
      
    
      
    Provedor e conexão
    Para evitar cobranças por uso de API, escolha Ollama local. Baixar modelos consome internet e espaço; a geração usa o hardware do computador/servidor.
    
      
    Modelos locais
    A lista vem do provedor. Modelos Ollama são processados localmente.
    
      
    API key remota (opcional)
    Provedores remotos podem cobrar. O JARVES não cria chaves; a chave salva fica protegida e nunca é exibida novamente.
    GPT-6.1 Sol (`gpt-6.1-sol`) é um modelo de API pago. Só aparece se o provedor remoto o listar.
